## 1. Коміт `bdbb3e2`: що з ним не так

Подивись `git show HEAD:src/redux/game/gameSlice.js`: у коміті редюсер
`moveExecuted` закоментований. Тобто **на цьому коміті гра не працює і тести
червоні**. Плюс у ньому змішано три речі: міграція ESLint, крок 1 і половина
кроку 2 (`applyMove.js`, `getMoveDetails`). Повідомлення
`crete 3-layer ehginr step 1` з помилками й нічого не каже рецензенту.

Чому це важливо: правило "після кожного коміту тести зелені" потрібне для
`git bisect` і для відкату. Якщо через місяць щось зламається, ти не зможеш
сказати "повернись на коміт кроку 1": там теж зламано.

Що робити: **історію не переписуй**, гілка вже запушена. Виправляй вперед:
наступні коміти зроблять гілку зеленою. Висновок на майбутнє:

```
npx vitest run && git commit
```

Коміт — лише після зеленого прогону. Повідомлення в стилі
`тип(область): що зроблено` англійською або українською, без скорочень.

## 3. `applyMove.js`: що лишилося

### Баг: `details.castling` — об'єкт замість літери

```js
castling: castlingRookMove,
```

`castlingRookMove` — це `{ from: 'h1', to: 'f1', side: 'K' }` або `null`.
Контракт і `buildSan` очікують `'K'` / `'Q'` / `null`. Зараз тести зелені
лише тому, що редюсер ще не викликає `applyMove`. Щойно ти підключиш його на
етапі 4.3 `gameslice-reducer-task.md`, впаде тест на `O-O`, а в history
потрапить об'єкт.

Не виправляй одразу. Спершу напиши тест на рокіровку в `applyMove.test.js`,
побач його червоним, і лише потім виправ. Це і є перевірка, що тест щось
ловить.

### Дрібниці

- Коментарі-пояснення правил (чому `captured` береться до перезапису, де
  стоїть жертва взяття на проході, чому промоція обов'язкова) досі є лише в
  `gameSlice.js`. Їм місце в `applyMove.js`. Перенеси їх, коли видалятимеш
  дублікати з редюсера.
- `castlingRights: castlingRights` → `castlingRights`, `captured: captured` →
  `captured` (скорочений запис властивостей).
- `@param {string | number} from` у `getCastlingRookMove` — клітинка завжди
  рядок. JSDoc має описувати правду.
- `ROOK_HOME_SQUARE_RIGHT` і `CASTLING_ROOK_MOVES` експортуються. Чи потрібні
  вони комусь назовні? Якщо ні, прибери `export`: що не експортовано, те
  можна вільно змінювати.
