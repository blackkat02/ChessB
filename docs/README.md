Правила:

- Статус задач — лише в `roadmap.md`. Готовий пункт видаляється звідти й
  описується в `architecture.md`.
- Завершений документ-задача переїжджає в `archive/` без правок змісту.
- Без номерів рядків і кількості тестів у тексті: вони застарівають за
  тиждень. Замість них — назви функцій і `grep`-перевірки.
